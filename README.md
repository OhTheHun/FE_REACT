# JotDown Client

JotDown Client là phần giao diện người dùng của hệ thống quản lý ghi chú JotDown. Ứng dụng được xây dựng bằng React và chạy độc lập với backend Laravel API.

## 1. Công nghệ sử dụng

- React
- Vite
- React Router DOM
- Axios
- Zustand
- TanStack Query
- Tiptap Editor
- Tailwind CSS
- Lucide React

## 2. Yêu cầu môi trường

Trước khi chạy project, cần cài đặt:

- Node.js
- npm

Kiểm tra phiên bản Node.js và npm:

```bash
node -v
npm -v
